## New findings, ranked

1. **P1 — `FetchGateway` lost its deadline guard around the full capture.** The old goroutine covered selection, dial, request write, response headers, and construction of the `Capture`. HEAD waits asynchronously for selection and dial, then runs the rest on the caller’s goroutine. A supplied stream whose `Close` fails to interrupt a header read can now keep `FetchGateway` blocked after the deadline. A successful header read that completes after cancellation can also return a `Capture` with a closing tunnel. The raw-socket hook bounds production SPDY I/O, but it cannot enforce the final result check. [fetch.go:98](/Users/ddoyle/Development/claude/kgwctl-claude-phase3/internal/proxydump/fetch.go:98) · [fetch.go:115](/Users/ddoyle/Development/claude/kgwctl-claude-phase3/internal/proxydump/fetch.go:115) · [fetch.go:149](/Users/ddoyle/Development/claude/kgwctl-claude-phase3/internal/proxydump/fetch.go:149)
2. **P1 — `Await` can block on late-result cleanup.** When both channels are ready and `select` chooses the result, `settle` calls `release` synchronously before returning `ctx.Err()`. If `select` chooses cancellation, cleanup runs asynchronously. The exported deadline guarantee therefore depends on which branch wins and whether cleanup blocks. `Fetch` supplies a callback that calls both stream `Close` and `stop`, with no nonblocking requirement on either. 3. **P3 — The new SPDY test can hang on a regression in the wait it exercises.** `TestPortForwardLateErrorStream` uses `t.Context()` without a deadline and calls `io.ReadAll` synchronously. Its deferred `Close` runs only after the read returns. Restoring the one-second grace would fail the assertion, but a regression that leaves `s.done` open stalls until the suite timeout. The test also skips the two teardown cases the timer removal relies on: cancellation and explicit `Close` while the error stream stays open. 4. **P4 — Per-Pod timeouts can leave two goroutines per outstanding dial.** `Await` starts a worker, then starts a second goroutine to wait for its result after cancellation. A hung credential plugin can hold the client-go authenticator lock while other captures queue behind it. When Phase 4 collects from multiple replicas, the global deadline can return control to the bundle caller while both goroutines per outstanding dial remain parked. The new known-Pod path inherits this cost, and the exported helper makes it available to other collectors.
