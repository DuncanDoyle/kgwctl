I would hold Phase 3.2 for two route-selection bugs, invalid-dump handling, and a correction to the published JSON contract.

### P1 · Correctness

- **`--route` can select a route with no resolved origin.** xdsview’s `origin.Annotate` leaves unknown origins nil. Its `filter.Filter` then falls back to substring matching. An Envoy route named `vhost-route-0-httproute-orders-team-a-0-0` lacks the `-matcher-<index>` suffix required by the origin parser, yet the fallback selects it for `--route team-a/orders`. The command can therefore attribute another route’s filter chain to `team-a/orders`, violating design §4.2. [internal/proxyview/view.go:104](/Users/ddoyle/Development/claude/kgwctl-claude-phase3/internal/proxyview/view.go:104) · [xdsview filter.go:153](/Users/ddoyle/go/pkg/mod/github.com/!duncan!doyle/xdsview@v0.4.0/pkg/envoy/filter/filter.go:153)
- **Two surviving candidates can hide a third, deleted candidate.** xdsview replaces the name-derived candidate list with the known subset whenever that subset is nonempty. It sets `NarrowedByKnown` only when exactly one remains. With `a-b-c-d`, the possible namespace/name pairs are `b-c-d/a`, `c-d/a-b`, and `d/a-b-c`. If the first two still exist, kgwctl keeps their reduced list and silently omits the Envoy route from the ambiguity report for `--route d/a-b-c`. Envoy may still serve that deleted route. [internal/proxyview/view.go:109](/Users/ddoyle/Development/claude/kgwctl-claude-phase3/internal/proxyview/view.go:109) · [xdsview kgateway.go:95](/Users/ddoyle/go/pkg/mod/github.com/!duncan!doyle/xdsview@v0.4.0/pkg/envoy/origin/kgateway.go:95)
- **A valid JSON file of the wrong kind exits 0 as an empty proxy.** xdsview accepts `{}`, `null`, and Kubernetes JSON objects because it unmarshals into a struct with an optional `configs` field. kgwctl then prints `no listeners` or `listeners: []` without a warning. A wrong attachment is indistinguishable from an empty dump. Validate the dump envelope while preserving support for a genuine `{"configs":[]}` and keeping Envoy parsing in xdsview under D-022. [internal/app/proxy_routes.go:325](/Users/ddoyle/Development/claude/kgwctl-claude-phase3/internal/app/proxy_routes.go:325) · [xdsview parser.go:47](/Users/ddoyle/go/pkg/mod/github.com/!duncan!doyle/xdsview@v0.4.0/pkg/envoy/parser/parser.go:47)
