I would revise the Phase 4b design and plan before implementation. The main blocker is that `--select known` can select a route without the text marker D-032 requires. The warning projection and first migration commit also need changes. D-031 and D-032 can stand as written.

## Findings

1. **P1 · correctness — The renderer can omit the required `known` marker.** DD-4 counts kept claims as one reading when they agree on route, rule index, rule name, and match index. DD-6 then passes those claims unchanged to `provenance.Labels`. In v0.7.0, the narrowed label path compares the entire `RouteSource`, so two claims that differ only in `IndexCertainty`, `Incomplete`, or `Exhaustive` can produce an `ambiguous:` text row for a route that JSON marks `chosenBy: "known"`. Task 4b.1.1 already proposes the `IndexCertainty` case, but only at the selection helper. Normalize the reading passed to the label hook and assert the chosen marker through text and JSON with a wrapping module. 2. **P2 · architecture — D-033 and D-034 need a warning projection that keeps module identity out.** `Compose` puts the generated claim ID, including the module name, in the `Message` of both `claim-dropped` and `link-dropped` warnings. Copying those warnings into the payload or text exposes the identity that DD-10 excludes. The recorded dumps and the valid wrapper in the plan do not exercise that path. Define kgwctl-owned messages for those codes, keyed by code and subject, and test a rejected claim under two wrapper names. 3. **P2 · architecture — Warning retention and warning rendering are different operations.** DD-12 requires every warning the tree did not print to appear at the end. A retained listener can have a sibling HCM with no routes after pruning. An ECDS warning on a downstream slot in that HCM survives `Prune`, while `render.Text` emits no downstream filter row there. A fallback based on `Full.Warnings` minus `Snapshot.Warnings` would lose the warning. The renderer also resets slot-warning tracking per route, so one slot warning can print under several routes. Specify how kgwctl accounts for warnings the renderer actually emitted, or simplify the contract to one complete warning list. Test a retained slot with no rendered row. Preserve a small typed unresolved-discovery indicator and test it without exporting raw configuration.
