Changes needed: overlapping aliases duplicate objects, the ListenerSet alias loses a required column, and three acceptance-test gaps remain.

1. **P1 — Overlapping targets print the same object twice.** [internal/resolve/resolve.go:76](internal/resolve/resolve.go:76) deduplicates only identical target sets. With both ListenerSet APIs served, `get ls,xlistenersets` retains `{ListenerSet,XListenerSet}` and `{XListenerSet}`. `GetTables` then appends the experimental objects twice, including in JSON/YAML `List.items`. The same occurs with `get all,xlistenersets`. Deduplicate overlapping kinds while preserving the accepted combined ListenerSet table.

2. **P2 — The ListenerSet alias omits GROUP when only one API is served.** [internal/view/get.go:147](internal/view/get.go:147) and line 191 gate GROUP on `len(t.Kinds) > 1`. Consequently, `get ls` loses GROUP when either ListenerSet API is unavailable. Design §3 and Task 1.2.3 require GROUP for the alias. Preserve alias identity separately from the number of served kinds. The resolver tests cover this serving configuration, but the command goldens always install both APIs.

3. **P3 — The held-watch test rejects an explicitly permitted outcome.** [internal/app/get_test.go:215](internal/app/get_test.go:215) fails when the command exits 0 with the complete healthy golden. Design §6.3 and Task 1.2.3 explicitly permit that result alongside exit 1 with denied and empty stdout. Delaying Deployments makes this a test of timing rather than the stated observable invariant. It also runs three iterations instead of the planned ten. Retain deterministic denial coverage separately and test the permitted invariant as specified.

4. **P3 — Named-lookup rulings lack regression coverage.** [internal/app/get_test.go:71](internal/app/get_test.go:71) tests an ordinarily visible named route; the not-found case at line 161 requests only one kind. Neither exercises bypassing ownership hiding nor `get k1,k2 name` where the first kind matches and the second does not. Add command tests across formats asserting the hidden object is returned by name, and that mixed-kind failure leaves stdout empty. These protect the explicit bypass and output-atomicity contracts.

5. **P3 — Policy ancestor deduplication is untested.** [internal/view/status_test.go:218](internal/view/status_test.go:218) covers distinct ancestors only. No case supplies multiple controllers’ entries for the same ancestorRef, so counting status entries instead of distinct references would still pass. Add a shared-ancestor case that verifies the denominator and owning-controller precedence.

I found no reason to overturn the supplied controller rulings. Sampled table/wide goldens otherwise follow §3.1. Tests were not run; validation relies on the author’s supplied results. No files were edited.
