## Remaining and new findings

1. **P1 · Remote response text can survive in `check.json`.** `load` copies cache errors into `Input.Reason`. The reused check path carries those strings into the report after a URL and host pass. Generic JSON redaction leaves a pattern-free response message intact. The plan’s standalone parity test can preserve this behavior even though D-026 requires status and reason codes only. Sanitize errors before reuse flattens them to strings, use canonical reason codes, and exercise a pattern-free denial body through the production bundle `check` path. The port-forward adapter also reads response text into errors today and needs to meet the same contract. [load.go:334](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/load/load.go:334), [check.go:297](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/app/check.go:297), [portforward.go:245](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/proxydump/portforward.go:245), [decisions.md:199](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/docs/decisions.md:199), [implementation-plan.md:253](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/docs/phases/phase-4/implementation-plan.md:253)

2. **P1 · Call 2 verifies the Deployment → Gateway link and infers the ReplicaSet → Deployment link.** In v2.5.1, the Gateway reconciler calls `SetNamespaceAndOwnerWithGVK` before applying the rendered objects. The deployer sets the Gateway’s kind, name, UID and `Controller: true` on the Deployment. The reader role grants Deployment reads only, so a matching Pod selector and ReplicaSet-name prefix cannot establish who controls that ReplicaSet. An unrelated or stale ReplicaSet with matching labels can therefore be attributed to the Gateway. To meet the binding ruling with the current role, skip the fallback when the chain cannot be verified. If ReplicaSet reads are approved, verify both owner links by UID. Also apply the post-capture re-read to logs, metrics and version, and define the recorded outcome when the Pod disappeared or the re-read failed. [gw_controller.go:335](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/.agents-tmp/pa/kgateway/pkg/kgateway/controller/gw_controller.go:335), [deployer.go:229](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/.agents-tmp/pa/kgateway/pkg/deployer/deployer.go:229), [rbac.yaml:47](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/docs/rbac.yaml:47), [design.md:229](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/docs/phases/phase-4/design.md:229), [implementation-plan.md:248](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/docs/phases/phase-4/implementation-plan.md:248)

3. **P2 · Calls 11–13 need a bounded writer lifecycle.** I would spill staged, **already-redacted** bytes to a `0600` temp file. At the default, 1 GiB is the staging allowance alone, before concurrent input buffers, parsed objects and bookkeeping. A larger archive limit raises memory exposure further. Use a fixed RAM budget, bound the spool and its index, and clean up the spool on success, cancellation and failure. The plan also needs a minimum supported `--max-size` or a reserve that fits smaller caps, plus a policy for oversized non-item manifest fields such as `replicas`. For sealing, define when late counters are sampled and who appends the truncation marker to an open text item. Finally, `io.Writer` and `Close` provide no cancellation contract. Returning from a timer can leave a write running during cleanup. Require a destination with testable cancellation semantics or change the file deadline guarantee and its gate together. 4. **P2 · Move the end-to-end gates to tasks that can exercise them.** Task 4.1.4 can replay artifact fixtures through the writer, but cannot exercise `-o`, flag recording or a registry kind resolving to `secrets` through that boundary. Task 4.2.2 can test the guard and inventory independently, but cannot assert the exact namespaced command request set before resources, workloads, `check` and logs exist. Keep the component tests in their current tasks and put the complete assertions after command wiring. Explicitly permit bootstrap’s cluster-wide watches or replace bootstrap with a list-only path.
