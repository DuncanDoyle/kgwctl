**Hold Phase 4.1 open.** The core can write credentials through supported redaction paths and manifest fields. It can also lose usable output or report it as collected when it never reached the archive. I reviewed `6ab915e..c96c05f` against the design, plan and brief. The findings are from source inspection. ## P1 — Correctness and leaks

1. **Prometheus validation accepts input that the redactor skips.** `expfmt` accepts tabs before a quoted label value and leading whitespace before comments. The rewrite only trims spaces after `=` and only recognizes comments starting in column one. A valid sample with `=` followed by a tab and a quoted `Bearer dummy-token`, or an indented `# HELP` line containing that token, reaches the archive unchanged. Make validation and redaction agree on the grammar and reparse the emitted fixture. [`prometheus.go:23`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/prometheus.go:23), [`prometheus.go:69`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/prometheus.go:69)

2. **Supported log and error formats can retain credentials.** The JSON debug-header rewrite splits on the raw characters `\n`, including inside an escaped backslash followed by `n`. For example, `{"msg":"headers:\n'x-tenant-key', 'dummy\\nsuffix'"}` splits the header before its closing quote, so no segment matches and the value survives. Separately, the free-text rule misses lowercase `basic` followed by an ordinary Basic credential, and `password="dummy two words"` retains `two words`. The same pattern pass handles errors and panic text. Test these at the archive boundary. [`headers.go:20`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/headers.go:20), [`pattern.go:26`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/pattern.go:26), [`errors.go:71`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/errors.go:71)

3. **Structured rules miss credentials inside accepted inputs.** `Object` uses the outer kind throughout the walk. A Kubernetes `List` containing a `DirectResponse` with a pattern-free `spec.body`, or a `ListenerPolicy` with a pattern-free custom header, bypasses the kind-specific rule. The writer already accepts Lists and checks their members for forbidden kinds. Separately, `JSON` leaves `{"password":123456}` untouched because literals never reach the key-name rule. Apply the member’s own kind in Lists and cover scalar credential values. [`object.go:34`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/object.go:34), [`walk.go:79`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/walk.go:79), [`walk.go:185`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/walk.go:185), [`walk.go:222`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/walk.go:222)

4. **Manifest enum fields accept raw text, and exclusion reasons can break finalization.** `Source.Identity` and `ExcludeReason` are string types. A collector that accidentally puts an error string such as `Bearer dummy-token` into either field writes it verbatim to `manifest.json`. With 1,025 distinct exclusion reasons, `capExcluded` computes a negative slice index and panics. One sufficiently large reason can also survive the minimal-manifest fallback and exceed the footer cap. Validate the enums at the Sink and check the actual encoded footer size before writing it. The same boundary needs a canonical remote-reason allowlist, since `Status.Reason: "DummyCredential"` currently clears the alphabetic check and reaches the footers. [`writer.go:234`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:234), [`writer.go:867`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:867), [`manifest.go:274`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/manifest.go:274), [`errors.go:54`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/errors.go:54)

5. **The staging and serialization limits leave large allocations outside the budget.** `Sink.Error` and rejected writes append records without charging the spool. A long sequence of distinct failed captures grows `records` even with an empty spool, and finalization builds every error line before applying the footer cap. Separately, compact JSON with several thousand nested arrays can expand past the entire bundle budget during indentation, before the writer checks its output length. Bound outcome and finding storage with omitted counts, build capped footers incrementally, and bound structured encoding before allocation. The forced text-marker write also needs reserved spool space. [`writer.go:212`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:212), [`writer.go:347`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:347), [`writer.go:694`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:694), [`tree.go:145`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/redact/tree.go:145), [`stage.go:113`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/stage.go:113)

6. **`Run` returns pre-commit results.** If a collector stages an item that later falls outside the archive budget, the returned manifest still marks it `ok`. The on-disk manifest marks the item `dropped`, but can still mark the collector `ok` because degradation was computed before commit. The returned manifest also bypasses the footer’s redaction and bounding, so a context containing a Bearer canary is scrubbed in the archive and retained in the return value. A command using that return value for summaries or `-o json` will report different results. Produce one sanitized, post-budget manifest for both consumers. [`run.go:122`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/run.go:122), [`run.go:137`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/run.go:137), [`writer.go:613`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:613), [`writer.go:658`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:658)

7. **Path conflicts can lose data despite a successful finalization.** `a/b` and `a/b/c` both commit as regular files, so an extractor cannot materialize both. Within one collector, concurrent `x/f.txt` and `X/F.txt` select a winner by completion timing. Across collectors, an oversized candidate claims its path in `seen` even when dropped by the archive budget, suppressing a later small candidate that fits. Resolve collisions in commit order and let only committed members claim paths. [`writer.go:285`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:285), [`writer.go:597`](/Users/ddoyle/Development/claude/kgwctl-claude-phase4/internal/bundle/writer.go:597)

8. **A commit panic leaves the destination behind.** Finalization defers spool removal, but only calls `Abort` on a returned error. The exclusion panic above can occur after member writes have started, leaving a partial archive at the exclusive output path. Also, `manifestFooter` discards encoding errors. An unencodable timestamp can leave an empty `manifest.json` while finalization succeeds. Propagate footer encoding errors and arrange destination cleanup on every unsuccessful exit. ## P2 — Design and plan mismatches

- **Map keys in findings must be masked before close.** A selector map such as `spec.selector.teamblue: "Bearer dummy-token"` redacts the value and repeats `teamblue` in `redactions.json`. The same issue affects `node.metadata`. Keeping keys in the source artifact is an acknowledged residual risk. Copying them into the report independently violates §7 and exposes them to anyone who receives just that report. Require schema-backed field names for literal locations and mask unknown keys conservatively, or obtain approval for a design change. The threat model currently says both that map keys are masked and that the heuristic can print them. A collector that substitutes credential-shaped text made of accepted path characters can copy it into the tar header and footers. Align the boundary with §8.4, including what the public `Path` type can guarantee and what collectors must guarantee about names.
