I found seven P1 issues in `38acaa0..f39a936`. The release blockers are in the request guard, diagnostic redaction, and collection bounds. The Envoy port-forward implementation itself uses fixed `GET` targets on port 19000 and refuses redirects.

### P1

1. **Correctness — The Secret and ConfigMap guard misparses some API server base paths.** Client-go prepends the configured server path to typed requests. `coreResource` uses the first `api/v1` pair anywhere in the resulting path. If the reverse-proxy prefix contains that pair, an ordinary typed Secret or ConfigMap request can reach the transport. D-026 requires the refusal on every bundle-owned client. Resolve the resource relative to the configured API base and cover prefixed servers at the HTTP boundary. Manifest preparation sanitizes the context, server and collector errors, leaving these fields untouched. A credential in either input can survive in the manifest. 9. **Architecture — Resource discovery and scope use different sets of kinds.** The resources collector enumerates only each group’s preferred version, plus registered kinds.
