## Findings

1. **P2 · Correctness — The new write-error contract omits SIGPIPE.** Both modes now print `Error:` and return 2 when the report writer returns an error. On Unix, if `head` closes stdout before `kgwctl` finishes writing, Go can terminate the process with SIGPIPE before the error handler runs. That behavior predates the fix, so `| head` retains its existing behavior. The new brief and output reference promise exit 2 for write failures without that qualification. Scope the promise to errors returned by the writer.
